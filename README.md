# Student Examination Portal

A premium, modern, production-ready Student Examination Portal for Arya College of Engineering & I.T. that provides students with a complete examination management system.

## Features

✨ **Complete Examination Management System**
- Student authentication and login
- Personal dashboard with student information
- Real examination results with actual mark data
- Official marksheet generation
- Print and PDF download capabilities
- Responsive design for all devices
- Professional university ERP styling

## Pages

### 1. **Home Page** (`index.html`)
- Hero banner with call-to-action
- Latest notices section
- Recent results display
- Quick links navigation
- Professional footer

### 2. **Login Page** (`login.html`)
- Glassmorphism design login card
- Password visibility toggle
- Remember me functionality
- Forgot password link
- Demo credentials display

### 3. **Dashboard** (`dashboard.html`)
- Personalized welcome message
- Complete student information display
- Photo placeholder and QR code sections
- Quick action cards (View Result, Marksheet, Admit Card, Downloads)
- Notifications feed
- Session-protected access

### 4. **Result Page** (`result.html`)
- Recreated examination result from actual data
- All 13 subject marks and grades
- Professional formatting
- Print functionality
- PDF download feature
- Subject-wise performance display

### 5. **Marksheet Page** (`marksheet.html`)
- Official marksheet layout
- Student details section
- Complete subject table with calculations
- Grand total and percentage display
- Signature section for officials
- Print and PDF download options

## Tech Stack

- **Frontend Framework**: HTML5, CSS3, Bootstrap 5
- **JavaScript**: ES6+ with vanilla JavaScript
- **Icons**: Font Awesome 6.4.0
- **Fonts**: Google Fonts (Poppins, Open Sans)
- **PDF Generation**: html2pdf.js
- **Responsive Design**: Mobile-first approach

## How to Use

1. **Open the Home Page**
   - Visit `index.html` in your browser

2. **Login to Dashboard**
   - Click "Student Login" button
   - Enter any non-empty username and password
   - Click "Login to Dashboard"

3. **View Results**
   - From dashboard, click "View Result" card
   - Review the examination result
   - Print or download as PDF

4. **View Marksheet**
   - From dashboard, click "Marksheet" card
   - Review the official marksheet
   - Print or download as PDF

## Installation & Deployment

### Local Development
```bash
# Using Python 3
python -m http.server 3000

# Or using Node.js (http-server)
npx http-server -p 3000

# Or using Live Server in VS Code
```

### Deployment to Vercel
1. Push code to GitHub
2. Connect repository to Vercel
3. Deploy directly from main branch

### Deployment to Any Hosting
- Simply upload all files to your web hosting
- No backend requirements
- Works with any static hosting service
